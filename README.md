# NextStep

Buildless student career learning prototype. Serve `dist` using any static HTTP server.

Includes seven illustrative career directions, course/year/technology preferences, introductory learning missions, reflection and quiz feedback, device-local progress, a project workspace, preparation checklist, and an editable printable resume.

This is a prototype, not a production education platform. No account backend, code execution, reviewed curriculum, live internships, mentor integration, or certification verification is implemented. Later roadmap modules are visibly unavailable. Preferences do not imply complete language-specific curricula. Subject review and student usability testing are required before rollout.
